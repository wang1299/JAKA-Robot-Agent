# JAKA-Robot-Agent

JAKA 具身机器人 Agent 的树莓派运行代码快照。

本仓库首次提交直接导出自树莓派 `/home/pi/jaka-robot`，不是电脑开发目录的副本。树莓派运行目录没有 Git 历史，因此此仓库从当前快照开始记录版本。

## 当前能力

- 网页及手机 PWA 对话、图片输入和后端离线语音识别。
- Qwen 决策与工具选择，MiniCPM 视觉分析。
- 地点导航、到点查看、巡逻、迎宾、参考图寻物。
- 拟物体地图查询、地图展示及任务确认卡。
- 共享相机与任务取消处理；移动仍须用户在任务卡确认。

当前会话上下文主要保存在服务内存中。讨论中的“独立、持久化会话记忆及任务结果完整回写”尚未实现，本快照不宣称具备该能力。

## 在现有树莓派环境启动

```bash
cd ~/jaka-robot
source ~/jaka/bin/activate
python robot_web.py --host 0.0.0.0 --port 8080
```

启动前确认端口没有被另一网页实例占用。已有模型隧道将树莓派本地 8000/8001 转发到视觉/决策服务；`tunnel.sh` 管理的是连接，不是服务器上的模型启动程序。`model_config.json` 保留当前本地接口与模型标识。

此仓库不是一键重建系统镜像：模型权重、Python 环境、系统依赖、SSH 密钥、Tailscale 状态及 systemd 配置不在项目快照内。硬件和网络地址需根据部署环境核对。地图及标定属于当前现场，不应直接用于其他场地的移动。

## 快照范围

包含树莓派现有 Python/HTML/脚本、PWA 文件、地图图标、地图 JSON、`slam.png` 和 `slam_calibration.json`。`SNAPSHOT.json` 记录导出时间与源文件 SHA-256，可用于核验版本。

不包含运行日志、拍摄照片、上传参考图、录音录像、RGB-D 数据集、轨迹记录、模型权重、凭据及电脑端测试脚本。导出期间没有修改运行源码、停止服务或执行机器人动作。
