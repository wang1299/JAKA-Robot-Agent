# 任务演示

本页收录两组任务的四段录像，每组包含实机视角和网页视角。仓库中的 MP4 为原录像的完整时长压缩副本，未剪辑、未加速；编码信息见 [媒体清单](demos/manifest.json)。在 GitHub 文件页面选择播放或下载；如浏览器未显示播放器，可下载后观看。

## 参考图寻物

![寻物预览](assets/find-preview.jpg)

- [DEMO-1-1 寻物实机演示](demos/DEMO-1-1.mp4)：机器人沿候选路线移动，并在目标附近进行观察。
- [DEMO-1-2 寻物网页演示](demos/DEMO-1-2.mp4)：参考图、任务过程与位置汇报。录像最终报告在木柜附近发现目标。

任务流程：上传物品照片 → 生成候选搜索计划 → 用户确认 → 逐点导航与视觉比对 → 汇报发现位置或未找到。现场比对结果决定是否发现，地图中的物体记录本身不代表实时发现。

## 迎宾接待

![迎宾预览](assets/welcome-preview.jpg)

- [DEMO-2-1 迎宾实机演示](demos/DEMO-2-1.mp4)：到接人点等待访客，确认后引导至送客点。
- [DEMO-2-2 迎宾网页演示](demos/DEMO-2-2.mp4)：任务状态和引导完成结果。

**版本差异：录像包含早期语音确认。当前源码使用主人网页照片确认：** 检测到参考图中的候选人物后，主人查看现场照片并点击确认；拒绝后继续等待，可随时取消。代码不会把访客的语音答复当成自动确认，也不会把外观相似当作身份认证。

这四段录像展示两个任务的早期实机过程。会话恢复、媒体管理及最新版确认逻辑应结合源码和离线测试查看；录像没有覆盖全部新版功能。
